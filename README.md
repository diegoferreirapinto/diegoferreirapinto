## 👋 Sobre mim

Sou desenvolvedor fullstack com atuação em sistemas web, automação de processos, soluções geoespaciais e modernização de aplicações legadas.

Tenho experiência na construção de ferramentas para controle operacional, gestão de dados, integração entre sistemas, painéis administrativos e aplicações voltadas para uso institucional e corporativo.
